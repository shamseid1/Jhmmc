# Claude-hosted version

`index.html` is a single-page version of the app published as a Claude artifact
(https://claude.ai/artifact/Qi7i1QkEYbPFWhMzuekT8V). It uses the artifact's
shared database and photo storage instead of the Node server, so clubs can use
it before the full app is hosted. Data entered there stays on that page and is
not shared with the Node app.
